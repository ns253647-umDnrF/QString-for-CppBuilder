# Изменения — 2026.11.11

## Поиск и совместимость Qt 5.15.2

- Прямой и обратный поиск строковых шаблонов используют линейный алгоритм KMP.
- Поиск без учёта регистра вычисляет ключи исходной строки по мере просмотра.
- Подсчёт совпадений строит таблицу шаблона один раз и учитывает перекрытия.
- Строковый `split()` повторно использует подготовленную таблицу разделителя.
- Строковые `contains()`, `lastIndexOf()`, `startsWith()`, `endsWith()`,
  `count()` и `split()` принимают `Qt::CaseSensitivity`.
- `toInt()` принимает основание системы счисления.
- `fromLocal8Bit()`/`toLocal8Bit()` используют системную Windows ACP.
- Запись через `QCharRef` за концом строки расширяет её и заполняет промежуток пробелами.

## Проверки и оформление

- До присвоения номера релиза полный рабочий прогон из 58 наборов завершился
  успешно. Его итог сохранён в `docs/full_audit_58.json`.
- Добавлен автономный релизный набор без зависимостей от Qt DLL, резервных копий
  и путей рабочей машины: эталонные данные, компиляция, интеграция и производительность.
- В заголовках обновлены только комментарии версии; исполняемая логика при
  подготовке архива не изменялась.
- Добавлены README, пример, документация тестов, сведения о происхождении
  эталонов, уведомление Unicode и SHA-256 содержимого архива.

Результат проверки распакованного пакета находится в `docs/package_test_results.json`.
